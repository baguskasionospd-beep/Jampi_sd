📊 Pusat Koneksi Google Spreadsheet Sekolah (Real-Time)

Seluruh media pembelajaran otomatis tersimpan di Google Spreadsheet milik sekolah Bapak/Ibu! Jika spreadsheet terlalu penuh (kode game HTML panjang), skrip otomatis memecahnya ke beberapa kolom agar tidak pernah gagal.

📋 LANGKAH 1: Pasang Kode di Google Spreadsheet Anda
  1. Buka Google Spreadsheet Baru (sheets.new) menggunakan akun Google Bapak/Ibu.
  2. Di menu atas Spreadsheet, klik Ekstensi (Extensions) → pilih Apps Script.
  3. Hapus semua kode yang ada di dalam editor, lalu klik tombol hijau "Salin Kode Google Apps Script (Code.gs)" di atas dan tempelkan (Paste) ke editor Apps Script, lalu tekan ikon 💾 Simpan.
  4. Klik tombol biru Terapkan (Deploy) di kanan atas → pilih Deployment baru (New deployment).
  5. Klik ikon roda gigi ⚙️ di sebelah "Pilih jenis" → pilih Aplikasi Web (Web app):
    • Jalankan sebagai (Execute as): Saya (Me)
    • Siapa yang memiliki akses (Who has access): Siapa saja (Anyone) ← Wajib dipilih agar siswa bisa melihat materi!
  6. Klik Terapkan (Deploy), berikan izin akses (Authorize access → Advanced → Go to project), lalu salin URL Aplikasi Web (berakhiran /exec).
